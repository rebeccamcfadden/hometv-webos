Only if you were asked to, and only if the TV's owner agrees. Work in progress, not tested on a real TV yet. Rooting can go wrong, and there is no "unroot" button. If nobody asked you to do this, stop here: HomeTV works without it, as an app (Install HomeTV).

Rooting an LG TV for HomeTV, and the way back

Rooting lets HomeTV open when you press Home and when the TV switches on, in place of LG's own Home. It is done together with the person helping you, on the phone. A program on the laptop does the work and checks each step. About an hour, plus the time to get ready.

Do this only after HomeTV was installed without root and worked (Install HomeTV on an LG TV). The same steps with more detail, for helpers: docs/root.md.

What root is, and isn't

  • It is using a mistake in LG's software to get full control of the TV. A free tool, SlopBro, does that from the laptop and puts the Homebrew Channel app on the TV. HomeTV then goes on through Homebrew Channel.
  • It changes only the TV's own storage for apps and settings: Homebrew Channel, a few of its switches, and two small start-up steps of HomeTV's. HomeTV takes the place of LG's Home only in memory, again at each start: a start without it gives LG's Home back.
  • It isn't new TV software. LG's own software is never changed, and nothing is "flashed".
  • It doesn't send anything anywhere, or touch your apps, accounts or settings.

The risk, in plain words

  • There is no unroot button. The full undo is LG's own factory reset. It works, but it clears all the TV's settings, apps and sign-ins. That's why the backup comes first.
  • A TV that won't start is possible, but rare. The ways back below cover it, from a restart to LG's USB recovery. The only known ways to a TV that even those can't fix are writing to LG's protected software or locking files; SlopBro, Homebrew Channel and HomeTV do neither.
  • The TV stays off LG's updates. An LG update usually ends root, so automatic updates stay off. That also means no security fixes from LG meanwhile. If an update comes anyway, LG's Home simply comes back (After an LG update).
  • It may void the warranty.
  • Only some TVs. LG fixed the mistake in software released after about October 2026. The program checks the TV's software version and stops on any it doesn't know.

Have these ready

  • The rooting program. The hometv-lg.exe from the check page can't root (it says it "leaves out the root install"). The person helping you sends you the one that can. Put it in your Downloads folder.
  • The backup file of this TV on the laptop: lg-backup-….json, in the HomeTV folder in your user folder. The install made one. If it's missing, run this in Command Prompt, in Downloads, with your TV's address:
    hometv-lg.exe check 192.168.1.50 --backup
  • Photos of the TV's settings screens, with your phone: picture, sound, the privacy switches, the order of the apps on Home, Power On Screen and Quick Start+, HDMI device links (SIMPLINK), the channel list if you use an aerial, accessibility.
  • A sign-in list, on paper: the apps you'd sign in to again, the LG account if there is one, the Wi-Fi name. No passwords on it; just make sure you know them.
  • A USB stick with LG's software for this TV (32 GB or smaller; it gets erased). It's for the very last way back. How to make it, step by step: The USB stick. Keep it in the laptop for the checklist: the program reads it.
  • Automatic updates off: Settings › All Settings › Support › Software Update › Allow Automatic Updates OFF (done during the install).
  • The remote, and an hour with the TV free. The laptop on the same Wi-Fi as the TV.

The steps

  1. Run the rooting program. In Command Prompt, in your Downloads folder, with the TV's address (the four numbers from the check):

    hometv-lg.exe root 192.168.1.50

    Change 192.168.1.50 to your TV's own address before pressing Enter.

    Before each step it says what the step does and how it's undone. It stops at the first thing that isn't right and says what to do. Run the same line again and it carries on where it stopped.

  2. The checklist. It checks the TV answers and the backup is on the laptop. Then it asks, one at a time: the photos? the sign-in list? which drive is the USB stick (type its letter, like E)? It reads the stick, and asks about automatic updates if the TV doesn't say. Type y or n and press Enter. Last, if the TV's owner agrees, type root.

  3. Clear the way. It asks you to delete HomeTV and the Developer Mode app on the TV, then to restart the TV: unplug it at the wall, wait 30 seconds, plug it in, turn it on (the remote's power button isn't a restart). The order matters: the Developer Mode app goes before root, and never comes back after. Then it checks that LG's Home and all your apps are there.

  4. The checks. The TV's software version (if the TV won't say, it asks you to read it in Settings › All Settings › Support › TV Information and type it), the stick again, and that the TV can reach the laptop. Windows may ask to allow the program on private networks: click Allow.

  5. Root. It says once more what happens. To start, type root the TV. The TV's browser opens and works for a while, then the TV restarts. Press Enter when it shows its Home screen.

  6. Open Homebrew Channel once from the TV's app list, wait for its list, then press Enter on the laptop. (That sets it to start with the TV.) If Homebrew Channel isn't there, the program stops: don't try again, tell the person helping you.

  7. HomeTV goes on. The program puts HomeTV back and locks the TV down: a key only this laptop has, the open doors closed, LG's updates blocked. Just wait.

  8. Restart and check. Restart the TV the same way (unplug, 30 seconds). The picture may stay black for about ten seconds: that's normal. Press Home; it asks Is it HomeTV on screen?. If HomeTV didn't come up, the program puts LG's Home back by itself and says so.

  9. The report. At the end it saves lg-root-report-….txt in the HomeTV folder (no address or serial number in it). Send it to the person helping you.

After an LG update

If the TV updates its software (by hand, or after automatic updates came back on), root usually ends. That is harmless:

  • LG's Home is back from the next start. When you open HomeTV from its tile, it may say so once: LG's Home is back.
  • HomeTV still works as an app: open it from its tile.
  • Nothing is broken. Your apps, inputs and settings are as they were.

Your choices, none of them urgent:

  1. Leave it as it is: LG's Home, and HomeTV as an app.
  2. Clean up: a factory reset (level 3), then HomeTV as an app again (Install HomeTV).
  3. Root again, only if a tool exists for the new software. Ask the person helping you.

Two cases that look alike:

  • Homebrew Channel still opens, but Home is LG's: root is still there. HomeTV stepped back because the new software is one it wasn't tried on. On the laptop, hometv-lg.exe root <tv address> --home-again explains it and asks before putting HomeTV back.
  • You chose Use LG's Home (level 1): that's your choice, not an update. HomeTV says nothing then.

On the laptop, hometv-lg.exe check <tv address> says Root: still on or Root: ended.

Good to know

  • HomeTV's own updates: Settings › Updates in HomeTV. Nothing is downloaded until you press Install update. If a new version doesn't start, HomeTV puts the old one back by itself.
  • Keep the USB stick, the backup file, the photos and the sign-in list for as long as the TV is rooted.
  • Never install the Developer Mode app again on a rooted TV: it can wipe Homebrew Channel and HomeTV. (hometv-lg.exe devmode refuses a rooted TV for that reason.)
