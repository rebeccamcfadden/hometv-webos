Install HomeTV on an LG TV

Done together with the person helping you, on the phone. First HomeTV v0 and its checks, then v1 installed over it. About 40 minutes.

The laptop check comes first, on its own page: HomeTV check for LG TVs. You need its program, hometv-lg.exe, and the TV's address from it.

What you need

  • The Windows laptop with hometv-lg.exe in your Downloads folder (from the check page), on the same Wi-Fi as the TV.
  • The LG Developer account details (an email and a password) from the person who sent you this link. Don't use your own LG account.
  • Your phone, on the same Wi-Fi, for v1.
  • The two HomeTV files below, in your Downloads folder.

Download both files

To check them (optional): open Command Prompt in your Downloads folder and run each line below; the long code it shows should match the one above.

certutil -hashfile com.hometv.app_0.0.1_all.ipk SHA256
certutil -hashfile com.hometv.app_0.1.0_all.ipk SHA256

Steps

  1. Turn on Developer Mode on the TV. Open the TV's app store (Apps, or LG Content Store on older TVs), search for Developer Mode and install that app. Open it and sign in with the LG Developer account details you were given. Then press Dev Mode Status to switch it ON. The TV restarts by itself.

  2. Open the Developer Mode app again after the restart, and press Key Server to switch it ON. Leave this screen open: you need the 6-letter passphrase shown at the bottom left (capital and small letters count).

  3. Get Dev Manager on the laptop. Dev Manager is a free Windows program, from the open-source webOS Homebrew project, that puts apps on the TV. In Command Prompt, in your Downloads folder (where hometv-lg.exe is), run:

    hometv-lg.exe get dev-manager

    It downloads the installer, checks it, and starts it. Windows asks Do you want to allow this app to make changes?: click Yes, then follow the installer.

  4. Add the TV in Dev Manager. Open webOS Dev Manager, click Add new device..., type the TV's address (the four numbers from the check, like 192.168.1.50) and any name. For the sign-in choose the option that uses the Developer Mode passphrase, and type the 6 letters from the TV's screen.

  5. Install HomeTV v0. In Dev Manager open the TV's Apps page, click Install, and pick com.hometv.app_0.0.1_all.ipk. When it finishes, HomeTV is in the TV's app list. Open it and go through its checks (Home › Checks for the TV call) with the person helping you.

  6. Install HomeTV v1 over it. In Dev Manager, Install again and pick com.hometv.app_0.1.0_all.ipk. It replaces v0 and keeps its settings; there is still one HomeTV. The person helping you then walks you through v1 (a key typed on your phone, the film lists, signing in).

  7. Key Server: OFF in the Developer Mode app (it's only needed to install).

Good to know

Developer Mode runs out after about 1,000 hours (about 41 days). Before that, open the Developer Mode app and press Extend; if it runs out, LG removes the apps you installed this way. Developer Mode also switches itself off after 10 restarts with no network.

To undo: in HomeTV v1, sign out first (Home › API keys › TMDB account › Sign out). Then delete HomeTV in the TV's app list, or delete the Developer Mode app (the apps go with it, and so do the keys saved for HomeTV).

If HomeTV can't be installed, the person helping you may ask for the separate test app instead: com.hometv.checks_0.1.0_all.ipk, release check-lg-v1, SHA-256 4e2be9d8706a21e4447106d3c8fa798248007d81e4c4cca85432bccf9e34ca44. Install it the same way as step 5.
