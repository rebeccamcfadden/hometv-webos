Install HomeTV on an LG TV

Done together with the person helping you, on the phone. First HomeTV v0 and its checks, then v1 installed over it. A program on the laptop does the installing and most of the checks. About 30 minutes.

The laptop check comes first, on its own page: HomeTV check for LG TVs. You need its program, hometv-lg.exe, and the TV's address from it.

What you need

  • The Windows laptop with hometv-lg.exe in your Downloads folder (from the check page), on the same Wi-Fi as the TV. If you downloaded it before 8 November, download it again: the older one can only check, not install.
  • The LG Developer account details (an email and a password) from the person who sent you this link. Don't use your own LG account.
  • Your phone, on the same Wi-Fi, for v1.
  • The two HomeTV files below, in your Downloads folder (the program downloads them itself; these are a spare, for the Dev Manager fallback).

Steps

  1. Turn on Developer Mode on the TV. Open the TV's app store (Apps, or LG Content Store on older TVs), search for Developer Mode and install that app. Open it and sign in with the LG Developer account details you were given. Then press Dev Mode Status to switch it ON. The TV restarts by itself.

  2. Open the Developer Mode app again after the restart, and press Key Server to switch it ON. Leave this screen open: you need the 6-letter passphrase shown at the bottom left (capital and small letters count).

  3. Switch off the TV's automatic updates, so the TV doesn't update itself during the checks. On the remote press the Settings button, then All Settings › Support › Software Update › Allow Automatic Updates. Note whether it was on, switch it OFF, and check that it now shows off. The program in the next step asks you about this, and it goes in its report.

  4. Run the install program. In Command Prompt, in your Downloads folder (where hometv-lg.exe is), run this with the TV's address (the four numbers from the check):

    hometv-lg.exe devmode 192.168.1.50

    Change 192.168.1.50 to your TV's own address before pressing Enter.

    (Or double-click hometv-lg.exe and type 2.) It downloads HomeTV v0 and v1 and checks them, asks for the 6-letter passphrase from the TV, installs v0, opens it and checks it, then installs v1 over it (it keeps v0's settings; there is still one HomeTV) and checks that. It asks you only plain yes/no questions, like Is HomeTV on the TV screen now?: type y or n and press Enter. If the TV asks to Allow the laptop, press OK on the remote. At the end it saves a report file (with no address or serial number in it): send it to the person helping you.

  5. Key Server: OFF in the Developer Mode app (it's only needed to install).

If the program can't install HomeTV: Dev Manager

Only if the person helping you asks for it. Dev Manager is a free Windows program, from the open-source webOS Homebrew project, that puts apps on the TV.

  1. In Command Prompt, in your Downloads folder, run:

    hometv-lg.exe get dev-manager

    It downloads the installer, checks it, and starts it. Windows asks Do you want to allow this app to make changes?: click Yes, then follow the installer.

  2. Add the TV in Dev Manager. Open webOS Dev Manager, click Add new device..., type the TV's address and any name. For the sign-in choose the option that uses the Developer Mode passphrase, and type the 6 letters from the TV's screen.

  3. Install HomeTV v0. On the TV's Apps page click Install and pick com.hometv.app_0.0.1_all.ipk (downloaded above). Open it and go through its checks (Home › Checks for the TV call) with the person helping you.

  4. Install HomeTV v1 over it: Install again and pick com.hometv.app_0.1.1_all.ipk. The person helping you then walks you through v1.

Good to know

Developer Mode runs out after about 1,000 hours (about 41 days). Before that, open the Developer Mode app and press Extend; if it runs out, LG removes the apps you installed this way. Developer Mode also switches itself off after 10 restarts with no network.

To undo: in HomeTV v1, sign out first (Home › API keys › TMDB account › Sign out). Then delete HomeTV in the TV's app list, or delete the Developer Mode app (the apps go with it, and so do the keys saved for HomeTV). If Allow Automatic Updates was on before, switch it back on (Settings › Support › Software Update).

If HomeTV can't be installed, the person helping you may ask for the separate test app instead: com.hometv.checks_0.1.0_all.ipk, release check-lg-v1, SHA-256 4e2be9d8706a21e4447106d3c8fa798248007d81e4c4cca85432bccf9e34ca44. Install it the same way as HomeTV in the Dev Manager steps.
