HomeTV check for LG TVs

A small program for a Windows laptop. It looks at your LG TV over your home Wi-Fi and writes a short report, so the person helping you can see whether HomeTV will work on it. About 10 minutes.

What it does, and doesn't

  • It reads the TV's model, software version, the apps and inputs it has, its sound output and a few picture and sound settings.
  • It may open Netflix and YouTube on the TV, only if you say yes, to see they open.
  • It opens the TV's web browser for a few seconds, to check the TV can reach the laptop.
  • It changes nothing on the TV: no settings, nothing installed, no accounts.
  • It sends nothing anywhere. The report stays on your laptop until you send it yourself.

What you need

  • A Windows laptop on the same Wi-Fi as the TV.
  • The TV switched on, and its remote.
  • About 10 minutes. No accounts or passwords.

Steps

  1. Download the program (about 96 MB):

    Download hometv-lg.exe

    File: hometv-lg.exe, release check-lg-v1. SHA-256: 2a51396c7b0e8497635a016e410c806b78e6058c67702be7a7c5fa74647a046f. To check it (optional): open Command Prompt in your Downloads folder and run the line below; the long code it shows should match.

    certutil -hashfile hometv-lg.exe SHA256

  2. Open it: double-click hometv-lg.exe in your Downloads folder.

    Windows will probably say "Windows protected your PC", because the program isn't signed by a company. Click More info, then Run anyway.

  3. Find the TV's address. On the TV, press the Settings button (the gear), then go to:

    All Settings › General › Network › Wi-Fi Connection › your network › Advanced Wi-Fi Settings › IP Address

    It's four numbers with dots, like 192.168.1.50. (If the TV uses a cable, it's under Wired Connection instead.)

  4. Type the address into the black window and press Enter.

  5. The TV asks to "Allow" this laptop. Press OK on the remote.

    Windows may ask whether to allow the program on private networks: click Allow.

  6. Netflix and YouTube: if you said yes, the window asks before opening each one. Answer y, look at the TV, type what happened (for example "Netflix opened" or "an error"), then press Back on the remote and Enter on the laptop.

  7. The TV's browser opens for a few seconds with the words "HomeTV: the TV reached the laptop". You can press Back.

  8. Done. The window says Done and a folder opens with a file named like lg-check-2026-11-05-18-30-00.json. Send that file to the person who sent you this link, as an attachment to an email or a message. Then press Enter to close the window.

What's in the report

In itNot in it
The TV's model and software version; its apps (names); its inputs (names like HDMI 1); its sound output; some picture and sound settings; whether Netflix, YouTube and the browser opened, and what you typed about them. The TV's serial number or device id; the TV's or laptop's address; your Wi-Fi name; any account, email or password.

The report is a plain text file (JSON): you can open it with Notepad to see everything in it before sending it.

If something goes wrong

  • "could not reach the TV": check the TV is on and on the same Wi-Fi, and that the address is typed exactly. Then double-click the program again.
  • No "Allow" on the TV, or it went away: run the program again and press OK as soon as it appears.
  • "TV reaches the laptop: no": that's fine for now; send the report anyway.

Afterwards

You can delete hometv-lg.exe and the HomeTV folder in your user folder. The TV remembers that it allowed this laptop; that only lets this laptop read the TV and open apps, nothing else.

Typing instead of double-clicking: open Command Prompt in your Downloads folder and run this, with your TV's address in place of the example:

hometv-lg.exe check 192.168.1.50 --backup --reach --launch

If you were asked to install the test app

Only if you were asked to. This is not needed for the check above. Still work in progress and not tested on a real TV. It puts a small test app on the TV; you can delete it again from the TV's app list. If nobody asked you to do this, stop here.

You need: the test app, and the LG Developer account details (an email and a password) from the person who sent you this link. Don't use your own LG account.

Download the test app

File: com.hometv.checks_0.1.0_all.ipk, release check-lg-v1. SHA-256: 4e2be9d8706a21e4447106d3c8fa798248007d81e4c4cca85432bccf9e34ca44. Save it in your Downloads folder. To check it, the same way as above:

certutil -hashfile com.hometv.checks_0.1.0_all.ipk SHA256

  1. Turn on Developer Mode on the TV. Open the TV's app store (Apps, or LG Content Store on older TVs), search for Developer Mode and install that app. Open it and sign in with the LG Developer account details you were given. Then press Dev Mode Status to switch it ON. The TV restarts by itself.

  2. Open the Developer Mode app again after the restart, and press Key Server to switch it ON. Leave this screen open: you need the 6-letter passphrase shown at the bottom left (capital and small letters count).

  3. Get Dev Manager on the laptop. Dev Manager is a free Windows program, from the open-source webOS Homebrew project, that puts apps on the TV. In Command Prompt, in your Downloads folder (where hometv-lg.exe is), run:

    hometv-lg.exe get dev-manager

    It downloads the installer, checks it, and starts it. Windows asks Do you want to allow this app to make changes?: click Yes, then follow the installer.

  4. Add the TV in Dev Manager. Open webOS Dev Manager, click Add new device..., type the TV's address (the four numbers from step 3 of the check, like 192.168.1.50) and any name. For the sign-in choose the option that uses the Developer Mode passphrase, and type the 6 letters from the TV's screen. The laptop must be on the same Wi-Fi as the TV.

  5. Install the test app. In Dev Manager open the TV's Apps page, click Install, and pick com.hometv.checks_0.1.0_all.ipk from your Downloads folder. When it finishes, the app is in the TV's app list.

  6. Tell the person who sent you the link that it's installed, and what the TV showed if anything went wrong.

Good to know: Developer Mode runs out after about 1,000 hours (about 41 days). Before that, open the Developer Mode app and press Extend; if it runs out, LG removes the apps you installed this way. To undo everything: delete the app in the TV's app list, or delete the Developer Mode app (the apps go with it). Also, Developer Mode switches itself off after 10 restarts with no network.
